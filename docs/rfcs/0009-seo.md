# RFC-0009: SEO最適化

## 1. Summary

検索エンジン最適化 (SEO) を実装し、Google/Bingでの検索順位向上とオーガニックトラフィックの獲得を目指す。

## 2. Motivation

- **オーガニック流入**: 「日程調整 ツール」「スケジュール 調整 無料」などの検索からの流入獲得
- **信頼性向上**: リッチリザルト表示でクリック率向上
- **技術的健全性**: Core Web Vitalsスコア改善

## 3. Goals / Non-Goals

### Goals
- robots.txt / sitemap.xml を設置
- 各ページに適切なメタデータを設定
- 構造化データ (JSON-LD) でリッチリザルト対応
- canonical タグで重複URL問題を回避
- OGP / Twitter Card を充実

### Non-Goals
- 有料広告 (SEM)
- バックリンク施策
- コンテンツマーケティング（ブログ記事等）

## 4. Design

### 4.1 robots.txt

```txt
User-agent: *
Allow: /
Disallow: /api/
Disallow: /event/*/edit

Sitemap: https://your-domain.com/sitemap.xml
```

### 4.2 sitemap.xml

Next.js App RouterのMetadata APIで動的生成:

```typescript
// app/sitemap.ts
export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  return [
    { url: 'https://your-domain.com', lastModified: new Date() },
    { url: 'https://your-domain.com/create', lastModified: new Date() },
    // 動的ページは必要に応じて追加
  ];
}
```

### 4.3 Per-Page Metadata

```typescript
// app/create/page.tsx
export const metadata: Metadata = {
  title: 'イベント作成 | 日程調整ツール',
  description: '会議やイベントの日程調整を簡単作成。候補日を選んでURLを共有するだけ。',
  alternates: {
    canonical: 'https://your-domain.com/create',
  },
};
```

### 4.4 JSON-LD 構造化データ

```typescript
// components/seo/JsonLd.tsx
export function WebsiteJsonLd() {
  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{
        __html: JSON.stringify({
          '@context': 'https://schema.org',
          '@type': 'WebApplication',
          name: '日程調整ツール',
          applicationCategory: 'BusinessApplication',
          operatingSystem: 'Web',
          offers: {
            '@type': 'Offer',
            price: '0',
            priceCurrency: 'JPY',
          },
        }),
      }}
    />
  );
}
```

### 4.5 OGP / Twitter Card

```typescript
export const metadata: Metadata = {
  openGraph: {
    title: '日程調整ツール',
    description: '...',
    url: 'https://your-domain.com',
    siteName: '日程調整ツール',
    images: [{ url: '/og-image.png', width: 1200, height: 630 }],
    locale: 'ja_JP',
    type: 'website',
  },
  twitter: {
    card: 'summary_large_image',
    title: '日程調整ツール',
    description: '...',
    images: ['/og-image.png'],
  },
};
```
