# UI/UXデザイン設計書

## 1. デザインシステム

### カラーパレット

| 用途 | Light | Dark | CSS変数 |
|------|-------|------|--------|
| Brand Primary | #0967D2 | #4A9EE5 | brand.500 |
| Brand Light | #EBF4FF | #1A365D | brand.50 |
| OK / 成功 | #38A169 | #48BB78 | green.500 |
| Maybe / 注意 | #D69E2E | #ECC94B | yellow.500 |
| NG / エラー | #E53E3E | #FC8181 | red.500 |
| おすすめバッジ | #38A169 | #48BB78 | green (Badge) |
| 背景 | #FFFFFF | #1A202C | - |
| テキスト | #1A202C | #E2E8F0 | - |

### タイポグラフィ

- **見出し**: Inter + Noto Sans JP
- **本文**: Noto Sans JP
- **数値/コード**: Inter
- **サイズ**: base=16px, sm=14px, xs=12px, md=18px, lg=24px, xl=30px

### スペーシング

- Chakra UIのデフォルトスペーシングスケール（4pxベース）
- カード内padding: 6 (24px)
- セクション間: 8 (32px)
- ページ幅: container.md (768px) for forms, container.lg (1024px) for tables

## 3. レスポンシブ対応

| ブレイクポイント | 幅 | 対応 |
|----------------|-----|------|
| base (mobile) | ~479px | 1カラム、テーブルは横スクロール、ボタンはfull-width |
| sm | 480-767px | 1カラム、テーブルは3列まで表示 |
| md | 768-991px | container.md、フォームは中央揃え |
| lg | 992px~ | container.lg、テーブルは全列表示 |

### モバイルでの特別対応

- 候補日テーブルの第1列（名前）はsticky
- 作成フォームのCandidatePickerはフルスクリーンモーダル表示
- アクションボタンはIconButtonのみ（テキスト非表示）
- 共有URLコピーはナビゲーターAPI（Share API対応時はネイティブ共有）

## 4. アニメーション

| 対象 | アニメーション | 仕様 |
|------|-------------|------|
| ページ遷移 | fade-in | opacity 0→1, 0.3s ease |
| カード | hover lift | translateY(-2px), box-shadow, 0.2s |
| ボタン | hover scale | scale(1.02), 0.15s |
| おすすめバッジ | fade-in | opacity 0→1, 0.5s delay |
| 回答完了モーダル | scale-in | scale(0.9→1) + opacity, 0.3s spring |
| Toast通知 | slide-in | translateX(100%→0), 0.3s |

**パフォーマンス方針**:
- `transform`と`opacity`のみ使用（GPU最適化）
- `prefers-reduced-motion: reduce` で全アニメーション無効化
- 新規アニメーション追加は行わない（既存Framer Motion実装を維持）

## 5. アクセシビリティ

| 対策 | 実装 |
|------|------|
| キーボードナビゲーション | `:focus-visible` outline styling（既存） |
| スクリーンリーダー | `aria-label` on icon buttons（既存） |
| カラーコントラスト | WCAG AA準拠（Chakra UIデフォルト） |
| OK/Maybe/NG区別 | 色 + テキスト（◯/△/×）の併用 |
| ピンチズーム許可 | `maximum-scale=5`（Phase 1bで修正） |
