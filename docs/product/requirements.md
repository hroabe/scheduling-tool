# 要求仕様（PRD）— 日程調整ツール v2.0

## 1. 背景 / 解決したい課題
- 複数人の空き時間調整を「URL共有だけ」で完結したい
- 回答状況を集計し、最適候補を提示し、確定まで一気通貫にしたい
- 回答期限のリマインドや通知の手間を減らしたい

## 2. ターゲットユーザー
- 小規模チーム/サークル/家族/学校行事の幹事
- 登録やアプリ導入が面倒な相手が混ざるケース

## 3. 価値提案（VP）
- 登録不要、URL共有で回答
- 直感UI（レスポンシブ/ダークモード）
- 自動集計、確定、CSV出力
- メール通知（回答通知/期限リマインダー）、通知ログ

## 4. スコープ
### In scope（現状）
- イベント作成（UUID共有URL）
- 候補日登録（開始/終了）
- ◯△×回答 / 編集（トークン）
- 回答期限 / 確定
- 通知（回答時メール、期限リマインダー、通知ログ）
- CSV出力 / 集計API
- 管理（編集キー認証、古いデータ削除）
- UI（ダーク/レスポンシブ）
- Mobile（RN基本）

### Out of scope（当面）
- 大規模組織向けの承認ワークフロー
- 複雑な会議室/リソース予約（まずは個人カレンダー連携優先）

## 5. 非機能要件
- 可用性: 個人〜小規模利用を想定（障害時の復旧手順を docs 化）
- 性能: 体感高速（集計はNが増えても破綻しない）
- セキュリティ: URL/トークン/編集キーの漏洩対策、PII最小化
- プライバシー: 参加者の個人情報を必要最小限に
- 保守性: 仕様と実装の同期（RFC/Docs必須）
- 運用性: 通知失敗の再試行、ログで追跡可能

## 6. ドメイン用語
- Schedule(Event): 日程調整イベント本体（共有URLは `uuid`）
- Candidate: 候補枠（開始/終了）
- Participant: 参加者（回答単位）
- Attendance: 候補×回答のレコード（◯△×）
- Edit Token: 回答編集用トークン（hash化済み）
- Edit Key: イベント編集/確定の管理キー（hash化済み）
