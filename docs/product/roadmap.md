# Roadmap

## 優先度: 高（収益化・差別化の核）
### M1: アカウント/認証
- 目的: 「自分のイベント一覧」「履歴」「連携設定」を提供
- KPI: 継続利用率、作成イベント数/週

### M2: Googleカレンダー連携
- 空き時間自動取得（候補提案）
- 確定日程を自動登録
- KPI: 確定までの時間短縮、幹事の工数削減

### M3: Outlookカレンダー連携
- Microsoft Graph API
- KPI: 法人利用の入口

### M4: Meeting URL 自動発行（Zoom/Teams/Meet）
- 確定時に会議URLを自動生成し通知
- KPI: “確定=招集完了” の体験

### M5: 1対1日程調整モード（Calendly風）
- 空き枠公開→予約
- KPI: 有料化/プラン分離の中核

## 優先度: 中（UX向上）
- LINE/Slack通知
- テンプレ複製
- QRコード
- i18n
- 締切後の自動督促
- パスワード保護 / IP制限
- リアルタイム更新（WebSocket）

## フェーズ設計（おすすめ）
- Phase A（2〜4週）: 認証 + マイページ + イベント管理
- Phase B（2〜4週）: Google連携 + 確定自動登録（Meetはここで自然に実現）
- Phase C（2〜4週）: Outlook連携 + Teams
- Phase D（3〜6週）: 1対1モード + 課金（別RFC）

## 計測（最小）
- 1イベントあたりの回答率
- 確定率（確定まで到達した割合）
- 確定までの平均時間
- 通知成功率/再試行回数
