# RFC-0010: レスポンシブデザイン改善

## 1. Summary

モバイル/タブレット向けのUI最適化。特にヘッダーナビゲーションのハンバーガーメニュー対応。

## 2. 現状分析

### 既に対応済み
- ✅ Chakra UIレスポンシブブレイクポイント使用 (`base`, `md`, `lg`)
- ✅ フォントサイズ・パディングが画面幅対応
- ✅ E2Eテストでモバイル(375px)/タブレット(768px)テスト済み
- ✅ `overflow-x: hidden` で水平スクロール防止

### 改善必要
- ❌ ヘッダー: ログイン/登録/各種ボタンがモバイルで詰まる
- ❌ ハンバーガーメニューなし

## 3. Design

### Header改善
```
Desktop (md以上):
[Logo] [新規作成] [ログイン] [登録] [🌐] [☀️] [GitHub]

Mobile (base):
[Logo]                              [≡ メニュー]
```

## 4. Implementation

### 変更ファイル
| ファイル | 変更内容 |
|---------|---------|
| `Header.tsx` | Drawer使用のモバイルメニュー追加、表示切り替え |

## 5. Test Plan
- E2Eテスト: 375pxでハンバーガーメニュー表示確認
- 手動: 開発サーバーでブラウザリサイズ確認
