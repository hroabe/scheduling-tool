# 競合分析: 日本B2C日程調整ツール市場

> 調査時点: 2026年3月24日（WebFetchによる最新情報確認済み）
> 対象: 本アプリ「登録不要・URL共有・CSV+ICSエクスポートのモダン日程調整ツール」の競合10サービス
> ベンチマーク: 調整さん（月間500万人利用、2006年開始）

| 項目 | 内容 |

## 批判的評価: 「登録不要 + CSV/ICSエクスポート」は本当に成立するか

### 楽観シナリオが成立する条件

本アプリのポジショニングは、マトリクス上では唯一「登録不要 × 日本語 × グループ投票 × CSV/ICS出力 × モダンUI × 無料」を全て満たす位置にある。しかし、マトリクス上の空白を埋めることと、市場で勝つことは別問題である。以下、批判的に検証する。

### 批判1: CSV/ICSエクスポートはユーザーの「欲しい機能」か

**懸念**: 日程調整の典型フローは「候補日を出す → 回答を集める → 日程を決める → LINEやSlackで共有」で完結する。「結果をCSVで出力したい」「確定日程をICSでカレンダーに入れたい」と思うユーザーがどの程度いるかは未検証。

- 調整さんにCSV出力がないのは「実装が難しいから」ではなく「需要がないから」かもしれない
- ICSエクスポートは便利そうに見えるが、実際のユーザー行動は「日程が決まったらGoogleカレンダーに手動で入れる」であり、その手動作業が十分に短い（30秒）ため、乗り換え動機として弱い可能性がある
- CSVエクスポートのユースケースは「幹事が参加者リストをExcelで管理する」程度に限られ、ニッチ

**反論**: フリーランスが「クライアントとの打合せ日程をカレンダーに即反映したい」というユースケースは合理的。ただしその場合、Spirのようなカレンダー連携ツールの方が本質的な解決策になる。

### 批判2: 「登録不要」と「再利用/定着」の根本的矛盾

**懸念**: 登録不要は初回利用のハードルを下げるが、ユーザーの識別ができないため以下の問題が生じる。

- 作成したイベントの管理: 管理URLの紛失 = データ喪失。これは調整さんと同じ構造的弱点
- 使用履歴・テンプレートの提供不可: 「前回と同じ設定で作成」ができない
- プッシュ通知・リマインダー不可: 回答期限のリマインドをメールで送れない
- マネタイズへの遷移困難: 01_strategy.mdで「マジックリンク認証で段階的に解消」と記載されているが、登録不要がコアバリューのツールで登録を求めることはブランドの自己矛盾になる

**反論**: 調整さんは同じ矛盾を抱えながら長年市場を維持している。ただし調整さんは「先行者優位 + 圧倒的認知度」という本アプリにはない資産を持っている。

### 批判3: 「モダンUI」は調整さんからの乗り換え理由になるか

**懸念**: UIの美しさはB2Cツールでは重要だが、日程調整ツールの利用時間は1回あたり数分。UIの良し悪しを感じる時間が短い。

- **重要な発見（WebFetch 2026年3月確認）**: 調整さんは2024年11月頃にトップページのビジュアルを更新し、さらにAIによるイベントメモ自動生成機能（シーン: カジュアル/ビジネス/お楽しみ、長さ: 短い/長いを指定可能）を追加している。これは調整さんがUI刷新とAI活用に動き始めていることを示しており、01_strategy.mdの「調整さんのUI刷新リスク」が現実化しつつある
- 調整さんのUIは古いが「壊れていない」。機能的に十分で、ユーザーの学習コストがゼロ。加えてAI機能で利便性向上を図っている
- 「UIがモダンだから乗り換える」というユーザー行動はB2Cの日程調整ツールでは起きにくい
- 乗り換えが起きるのは「既存ツールでできないことができる時」だが、CSV/ICSがその「できないこと」として十分強いかは前述の通り疑問
- なお、2023年3月時点で調整さんの月間利用者数は500万人を突破しており（WebFetch確認済み）、関連サービスとしてTimeRex（日程調整自動化）と調整さんビジネス（法人版）も展開している

### 批判4: 真の競合はLINEスケジュールであり、そこでは勝てない

**懸念**: 本アプリの初期ターゲット「大学生/サークル」の日程調整は、現実にはLINEグループで行われる。

- 「このURL開いて回答して」より「LINEのグループでポチポチ」の方が圧倒的に摩擦が少ない
- LINEスケジュールはLINEの配信力で回答率がほぼ100%になる。URLベースのツールでは「URLを開かない人」問題が常に発生する
- この層を取るには「LINEではできないこと」を訴求する必要があるが、CSVエクスポートは学生の関心事ではない

### 批判5: 市場自体が「十分に良い」ソリューションで飽和している

**懸念**: 日程調整は「解決済みの問題」に近い。調整さん、LINEスケジュール、Googleカレンダーの3つで大半のユースケースがカバーされている。

- 「不便だが我慢している」ユーザーはいるが、その不便さ（UIの古さ、エクスポート不可）は乗り換えコスト（新しいURLを共有する習慣変更）を上回るほどの痛みではない可能性
- 日程調整ツールはネットワーク効果が働く（皆が使っているツールが便利）ため、後発が巻き返すのが構造的に困難

### 総合評価

| 観点 | 評価 |
|------|------|
| ポジショニングの論理的整合性 | **成立する**。マトリクス上の空白は確かに存在する |
| 空白の需要が実在するか | **未検証**。CSV/ICSエクスポートへの需要は仮説段階 |
| 初期ターゲットへの訴求力 | **弱い**。大学生にはLINEスケジュール、フリーランスにはSpirが現実的な選択肢 |
| 持続的な差別化になるか | **疑問**。CSV/ICSは機能であり参入障壁ではない。調整さんが1週間で実装可能 |
| 成長ポテンシャル | **限定的**。登録不要モデルではLTV向上策が取りにくく、バイラル以外の成長レバーが少ない |

### 提言

ポジショニング自体を否定するのではなく、以下の修正を検討すべきである。

1. **初期ターゲットの再定義**: 「大学生/サークル」ではなく「副業・フリーランスの対外調整」や「小規模イベント主催者（勉強会、もくもく会）」に絞る方が、CSV/ICSの需要と合致する。エクスポート機能に価値を感じるのは「調整結果を別のシステムで管理する必要がある人」である

2. **キラーフィーチャーの再検討**: CSV/ICSエクスポートは「あると嬉しい」であり「乗り換える理由」ではない可能性がある。むしろ「確定後にGoogleカレンダーにワンクリック追加」（OAuth不要のICSダウンロード方式）を前面に出し、「日程が決まった後の面倒を解消」というストーリーで訴求する方が響く

3. **調整さんの弱点への集中攻撃**: 「作成後の編集」は調整さんユーザーの明確な不満点（作り直し問題）であり、CSV/ICSよりも乗り換え動機として強い可能性がある。こちらをメインの訴求ポイントに据え、CSV/ICSはサブ機能として位置づける方が現実的

4. **「登録不要だがブラウザに記憶」モデル**: localStorageで作成したイベントの履歴を保持し、「登録不要なのに自分のイベントを管理できる」体験を提供する。これは登録不要のブランドを維持しつつ、定着率を高める現実的な方法（01_strategy.mdでは未言及）

## 結論

「登録不要 + CSV/ICSエクスポート」というポジショニングは**論理的には成立するが、市場的に成立するかは未証明**である。マトリクスの空白が需要の空白と同義とは限らない。最大のリスクは「誰も困っていない問題を解決しようとしている」可能性であり、MVPリリース後の早期ユーザーインタビューで、CSV/ICSエクスポートが実際に利用・評価されているかを定量的に検証すべきである。

ただし、「登録不要 + モダンUI + 作成後編集」の組み合わせは、調整さんからの乗り換え動機として現実的であり、CSV/ICSはそこに付加価値を加える差別化要素として機能しうる。重要なのは、CSV/ICSを「メインの武器」ではなく「追加の引き出し」として位置づけ、ユーザー獲得のメインストーリーを「調整さんの不便を解消するモダンな代替」に据えることである。
